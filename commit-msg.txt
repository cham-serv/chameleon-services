feat: shared infrastructure (batch 3)

Adds the data layer, SEO, and plumbing that every template page needs:

### API Client (src/lib/api.ts)
- Typed fetch functions for all engine endpoints: products, articles,
  services, FAQs, legal docs, page-seo, categories, topics
- ISR cache tags for targeted on-demand revalidation
- Single/list endpoints for products, articles, services
- Paginated response type matching Payload's shape

### SEO (src/lib/seo.ts)
- generatePageMetadata() — fetches PageSEO record from engine,
  falls back to tenant config defaults
- generateItemMetadata() — for detail pages (products, articles)
- OpenGraph and Twitter card generation

### JSON-LD (src/lib/jsonld.ts + src/components/JsonLd.tsx)
- Builders: Product, Article, FAQPage, Service, Organization,
  BreadcrumbList, LocalBusiness
- JsonLd component renders script tags with XSS escaping

### Currency (src/lib/currency.ts)
- formatCurrency() — converts cents to display strings (ZAR, USD, EUR, GBP)
- getCurrencySymbol() and formatPriceValue() helpers

### ISR Revalidation (src/app/api/revalidate/route.ts)
- HMAC-SHA256 authenticated endpoint
- Replay protection (5-minute window)
- Tag sanitization and rate limiting (max 20 tags per request)

### Dynamic SEO Files
- robots.ts — blocks demo tenant indexing, allows production
- sitemap.ts — queries engine for all published content per tenant
